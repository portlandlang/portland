# 0053 — Constants: a SCREAMING_CASE name at the top level is bound once, with a def's reach

- **Status:** Accepted (recommended and built in both oracles, 2026-09-24, under the deciding user's standing "make the case, recommend, build; course-correct after")
- **Date:** 2026-09-24
- **Issue:** [#97](https://github.com/portlandlang/portland/issues/97), out of [#95](https://github.com/portlandlang/portland/issues/95)

## Context

ADR 0021 said constants needed no new concept: `MAX = 5` was already unrebindable, and all that was missing was a place for the name to live, which namespaces supplied. Probing #95 found the half that did not hold: a top-level `SOME_SIGNIFICANT_NUMBER = 8_675_309` was a *local*, with a local's reach — unreadable from inside any def, and not crossing a require. The thing a constant is for — a named value every def in the program reads, and every file that requires this one — was exactly the reach a def has and a local does not. `def LIMIT = 9` had that reach already, on both oracles, but reads as a method.

The deciding user's lean was yes, for Ruby reading ergonomics: a Rubyist reads `SCREAMING_CASE` as a named fixed value at a glance, and migrating code carries thousands of them. Their proposal was sugar for `def NAME = value`, with the ladder recorded on #97; this ADR takes the ladder's recommendations.

## Decision

1. **The shape.** A binding whose name is two characters or more, starts with a capital, and holds only capitals, digits, and underscores is a constant when written at the top level of a file. In a module body it is that module's constant, as ADR 0021 already had it, qualified `Config::LIMIT`. Inside a def or a block-in-a-def an uppercase name is an ordinary local, since a def is its own scope. A single capital alone at the top level — `X = 1` — is neither shape and refuses: `'X' is a single capital — spell a constant with two characters or more, a local in lowercase`. `CamelCase` stays the type shape and is untouched.
1. **The reach is a def's.** Read from inside every def, struct method, and block in the program, and from every file that requires the file that bound it (which settles #95's remaining half: locals never cross, constants do). On the seed a constant lives in its own table beside the methods; hosted, it is a binding whose tag survives a method scope and a require.
1. **Bound once, from anywhere.** A second `LIMIT = 10` at the top level, inside a def, or in a module body says `'LIMIT' is a constant — it is bound once`. `mutable LIMIT = 9` says `'LIMIT' is a constant — a constant cannot be mutable`. A constant named after a def, or a def after a constant, is ADR 0052's `'LIMIT' is already defined — rename one`. The `mutable` rewrite the old sentence offered was the wrong next step for something spelled as a constant; these are the constant's own words.
1. **The value is computed once, at definition.** Not sugar for a def after all — a def runs its body on every call, and `TABLE = build_table()` would rebuild on every read, a cost trap and a semantic one if the right side has an effect. Ruby evaluates a constant once; so does Portland. The pipeline (#5) may later inline a literal right side at every use, sound exactly because a value never mutates; nothing here is in its way.
1. **The checker** treats a top-level constant as a global at its value's inferred type, so `LIMIT.upcase` on an integer constant refuses inside a def the way any typed name does, and every rebinding above refuses at build with its line.

## Consequences

- No-shadow (ADR 0001) is complete for constants: a name is a local, a method, or a constant, never two.
- ADR 0021's "constants need no separate concept" is superseded on that sentence: the mechanism is small, but it is a concept — a binding with a def's reach.
- Ruby code that reassigns a constant (a warning there) refuses here; `Module.const_get` and friends are the metaprogramming ADR 0004 dropped. Ledger: [constants.md](../ruby/constants.md).
- Pinned by a two-oracle evaluator test (reach inside defs, struct methods, blocks; beside a module's constant of the same name), the refusal rows of ADR 0052's test, and `spec/namespace/top_level_constant_spec.pdx`.
